1. Spatial Attribution Analysis:

The data used for spatial attribution includes the relationship between ALAN and DFS for each city, as well as the influencing factors that affect the ALAN-DFS relationship in each city.

2. PCMCI+:

Cities where the partial correlation between the two variables is significant are retained as input data.

3. DFS Models:

Input data for the phenology model:

(1) ALAN.npy: ALAN data for 452 cities from 2001 to 2022
(2) DFS.npy: DFS data for 452 cities from 2001 to 2022
(3) SOS.npy: SOS data for 452 cities from 2001 to 2022
(4) photoperiod.npy: Photoperiod data for 365 days in 452 cities
(5) temp.npy: Daily temperature data for 452 cities from 2001 to 2022
(6) Tss.npy: Spring and summer temperature data for 452 cities from 2001 to 2022
