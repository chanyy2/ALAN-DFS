All code is executed in Python 3.8.10.

1. Installing Python 3.8.10
   - Extract the downloaded 'python-3.8.10.zip' file
   - Right-click 'python-3.8.10-amd64.exe' and select "Run as administrator"
   - Follow the installation wizard to complete setup

2. Installing Dependencies
   - Run the following command in your terminal:
     pip install -r requirements.txt
